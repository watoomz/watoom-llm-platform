## Break a new game into small tickets before building it
When a game project has no ticket yet for its own build (a brand-new project, or an existing one with no open/closed ticket under its queue folder), do this before writing the first line of game code, even before `gg_project.py init` or the Unreal equivalent:
1. If the mechanics, scope or rules are not already decided, call `watoom-game-designer` first (per the specialist gate): decomposing an undecided game produces guessed tasks, not real ones.
2. Break the whole game into small, independently-completable tasks: one task per stage script run, one per system (player controller, one per weapon/ability, one per level/area, one per UI screen, one per asset pack to survey/convert/wire in), one per verification pass. A task should be small enough to finish and verify in one sitting; if a task still sounds like "build the combat system," split it further (attributes, one weapon, one spell, hit detection, death/respawn, UI feedback are each their own task). There is no upper limit on how many tasks this makes -- the owner would rather have fifty small tickets than five big ones a model gets stuck on. Order them (a dependency can't start before what it needs), but file all of them now, not only the first few.
3. File every task as its own ticket under the project's ticket system (`watoom-tickets` skill, `<project>/.opencode/tickets/<id>.json`, same mechanics as the Tickets section above). You are the creator, so you are the owning model on each one; put your model name in every ticket as usual. Use the body for what "done" means for that one task (the concrete, checkable result), not a restatement of the whole game.
4. Start work on the first unblocked ticket, moving it `doing`; as each task finishes and verifies, mark it `done` with its evidence and move to the next. The checkpoint/ticket-note piggyback rule above applies to every one of these tickets the same as any other.
Re-run this breakdown step (added tickets, not a redo of finished ones) when the owner changes the game's scope enough that the existing ticket list no longer covers it.
