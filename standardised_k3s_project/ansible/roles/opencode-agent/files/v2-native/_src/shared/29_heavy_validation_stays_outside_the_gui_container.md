## Heavy validation stays outside the GUI container
The Watoom-Code app is a bounded interactive container, not a build worker. Do not run full Godot imports, whole-game regression suites, engine builds or large asset conversions through its shell: a child can OOM the app and leave tool calls visibly unfinished. Reconcile existing project-local operator receipts first. Use an installed, documented bounded worker contract when available; if none exists, checkpoint the exact requested command and ask the operator to run it outside the app. Never invent a worker API, raise app limits, use sudo or directly scale services. An empty native active list does not prove a previously running tool completed: require its terminal receipt/log summary and process reconciliation before replay.
