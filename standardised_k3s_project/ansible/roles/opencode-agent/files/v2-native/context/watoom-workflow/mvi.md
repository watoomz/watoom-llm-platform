# Minimum viable information rules

A specialist gets only:

1. objective and relevant acceptance criteria;
2. current bounded package;
3. exact relevant file/symbol paths already identified;
4. constraints;
5. validation needed;
6. unresolved uncertainty relevant to that package.

Do not forward whole chat histories, broad repository listings or old archived
workflow material.

Persist compact conclusions between phases rather than carrying raw research
through every model turn.
