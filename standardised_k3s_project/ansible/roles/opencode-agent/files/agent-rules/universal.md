# Universal engineering rules
- Inspect evidence before editing and make the smallest coherent change.
- Preserve repository architecture, naming, formatting and tooling unless explicitly changing them.
- Do not invent dependencies, APIs, flags, test frameworks or build systems.
- Discover and use configured build/test/lint/formatter/package tooling.
- Do not rewrite unrelated code or disable checks merely to obtain a pass.
- Distinguish implementation defects from unavailable tooling or missing evidence.
- Report only verification actually executed; inspect dependent results before continuing.
- Do not install packages, stage, commit, push, reset, clean or broadly restore unless authorized.
