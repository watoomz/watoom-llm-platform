# Graphic novel working templates

Use only sections needed for the requested deliverable. Resolve fields in real
project output; this reference is a reusable template, not finished art.
The comic root is adaptations/comics/ for a story adaptation, comics/ for a
standalone original, or the author's existing folder.

## Project brief and visual bible

- Title / logline / audience / genre / emotional promise / ending
- Original or adaptation; source project/scene ids when applicable
- Art style described in visual terms; character/location reference ids
- Print, fixed-page digital or vertical scroll; reading direction
- Story page/episode budget; first finishable milestone
- Trim/canvas, palette, linework/tones, lettering conventions
- Character proportions, wardrobe versions, signature props and locations
- Stage ledger: page id | script revision | art-note path/revision | planned assets | generation state | lettering | review

## Page plan

| Page/scroll beat | Source scene | Purpose and change | Panels | Dialogue load | Turn/reveal | Continuity |
|---|---|---|---|---|---|---|
| 1 | original-scene-01 | Establish the signal tower; a light fails | 3 | sparse | Set up a missing signal | Storm; intact coat |
| 2 | original-scene-01 | The keeper discovers another light below | 3 | sparse | Reveal on actual next spread | Same storm and coat |

Check physical pagination and facing spread before promising the reveal. A
vertical-scroll plan records screenful spacing rather than odd/even page parity.

## Full script / illustration brief

PAGE 1 - 3 PANELS
Source scene: original-scene-01
Purpose: The dependable lighthouse signal fails.
Reading direction: left-to-right
Continuity: keeper-kai, coat-v1, tower-top, night-storm

PANEL 1. Wide establishing view of the tower against dark water.
The lantern is bright. Kai is visible at its window.
Composition: leave a quiet sky area for the caption.
1. CAPTION: One light meant home.

PANEL 2. Close view of the lamp housing. Its filament is dark.
2. SFX: tik

PANEL 3. Medium view of Kai holding the dead lamp.
Expression: concern, shifting toward resolve.
3. KAI: That should not be possible.

Production notes: use established palette/ref ids and the scene's line weight.
Do not print these notes. Keep exact lettering separate from image prompts.

## Persistent page-art note

Save one page note using the schema/example in graphic-novel-art-notes.md.
Include story context and purpose, before/after continuity, numbered visible
panel moments, character/reference/wardrobe ids, composition and emotion,
essential clues/props, palette, balloon reserve and exact text separately.
Record source revision and update the illustration manifest at the same time.
Do not leave any drafted page with an unrecorded illustration requirement.
