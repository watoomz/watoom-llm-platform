# Rendered scene capture contract
Copy godot-scene-capture.gd into the selected project validation folder. Instantiate as a Node3D scene; set actual scene_path, output_dir and bounded named views with position/target/fov. Discover subject bounds and orientation from actual scene/runtime evidence; never guess reusable world coordinates. Record source revision/hash manifest in the worker receipt. Use deterministic setup hooks for moving scenes and capture multiple times for animation. Do not reconstruct a simplified world when judging the actual game. If an asset-only staging scene is needed, label it separately and preserve exact materials/dependencies.

Run through the existing approved bounded rendered worker, with Xvfb/GL Compatibility only where actually supported. Headless parsing is syntax validation only. The template fails on missing scene/views, invalid camera geometry, camera replacement, missing framebuffer, save errors. It retains origin and world-up explicitly, removes previous capture cameras, waits for frame completion and emits pixel hashes plus actual camera/renderer diagnostics. These are capture receipts, NEVER visual PASS receipts.

Independently inspect each exact image with verified vision and v2 receipts. Also assess task-specific criteria (subject readable at useful scale, level horizon unless intentionally tilted, requested terrain/materials/foliage visible, sufficient views). A usable-frame PASS does not establish task acceptance. Diagnose source/runtime causes separately; a changed hash proves only changed bytes. Keep every failed/intermediate PNG under standard project captures so the common /data/ai/projects/images/review collector retains it. Preserve original files and worker job identity.

For rejected composite-asset captures, load watoom-engine-visual-diagnosis. asset-scene-mesh.gd is a shared game/capture template for static vegetation assembly: highest-detail components, node transforms, authored material overrides and texture cutouts. asset-scene-regression.gd demonstrates a bounded runtime check; adapt its exact project paths and run through the approved external worker, never full scene loading in the app. Use actual instance AABBs for framing and retain original source materials. These templates do not confer final visual acceptance.
