# Tools: SD File Manager

**Menu path:** Tools → **SD File Manager**

## What it does

Browse the **SD card** on-device: open folders, view files, delete or manage per implementation (`SdFileManager` in firmware).

## How to use

1. Insert a **FAT** SD card; wait for **SD OK** in status if shown.
2. Open **Tools** → **SD File Manager**.
3. Navigate with touch / keys as the UI indicates.

Avoid deleting **`/config/settings.json`** unless you intend to reset preferences. Captures often live under **`/captures`**; ducky scripts under **`/ducky`**.
