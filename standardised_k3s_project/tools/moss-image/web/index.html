What do these settings do?
Camera / film look
Each preset wraps your scene as look, scene, look and adds that look's own avoid-list. Write only what is in the picture; leave the grain, colour and lens to the look. Pick “No look” to use your text as written.
Size
Width × height in pixels (multiples of 16, up to about 2.1 megapixels). 1216 × 832 is the tested default. Larger sizes take longer and need more VRAM; pick portrait or landscape to match the subject.
Steps (1–60)
How many refinement passes the model makes. Fewer is faster but rougher; more is slower with diminishing gains. The default of 25 is a sound starting point.
CFG (0–10)
How strictly the picture follows your text. Low (about 2–3) looks looser and more natural, which suits photo looks. High values follow the text literally but can look harsh or over-processed. Default 2.5.
Sampler
The method used to remove noise step by step. Different samplers give different details from the same seed. The default, er_sde, is the one tested here; try others to compare. Methods with “ancestral” or “sde” in the name add fresh randomness each step.
Seed
The starting noise. The same seed with the same text and settings repeats the same picture, so keep a seed you like and change one thing at a time. Blank means a new random seed every run.
Extra negative prompt
Things to keep out of the picture (for example “text, watermark, extra fingers”). It is added after the avoid-list that comes with the look.
GPU session
The image model needs the GPU, which the language model normally holds. Start GPU session starts as soon as WatooM Code is not running anything, then pauses the language model. The session ends after 10 idle minutes, when you press End, or after 2 hours, and the language model is restored. Restoring takes a few minutes.
