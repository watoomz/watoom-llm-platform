# Installed game template catalogue

The owner-requested Godot and Unreal sources live in `/data/ai/game_templates`, outside Git. Each project/component has an independent engine/category/id directory. Preserve the originals; never merge starter projects into one directory or automatically replace an existing game.

`sources.json` pins the Godot sources: six Git revisions and one owner-requested itch.io archive (Third Person Shooter Template, by SHA-256). `download-itch.py` fetches pinned free itch.io archives into `godot/.downloads/<id>`, skips verified downloads and rejects any hash mismatch. `install.py` checks clean detached Git sources or the pinned archive hash, licence notices, project descriptors, Git LFS and contained paths without executing template code. `archive.py` holds the safe ZIP extraction shared with `install-unreal.py`. `unreal-sources.json` records the three owner-provided public download links and original store URLs. `download-unreal.py` uses the verified Fedora megatools helper, supports its resumable transfers and skips completed downloads. Original Unreal ZIPs stay under `unreal/.downloads`; `install-unreal.py` checks archive integrity, contained paths, duplicate names and source hashes without running code. Per-template records/manifests live under each engine's `.catalogue/records`.

Run `python3 catalogue.py --skills ../../ansible/roles/watoom-code/files/skills` from this directory to rebuild the combined JSON/Markdown catalogue and short native skill records. Install generated records using the existing managed skills deployment. Native `watoom_skill_search` searches by engine, genre, mechanics or template name. Its numeric limit is an integer 1..32. Load the chosen `game-template-*` skill; metadata `opencode/autoinvoke: false` keeps instructions manually selected. Do not invent a new tool name.

Read-only local search: `python3 search.py "multiplayer FPS" --engine godot --limit 4`. Combined data: `/data/ai/game_templates/catalogue.json`; human index: `/data/ai/game_templates/CATALOGUE.md`.

Source installation is not runtime qualification. All ten entries are `NOT_TESTED` for engine execution. Use the existing bounded external worker and review gates on an approved copied project. Preserve licences, third-party notices, textures, rigs and Unreal content namespaces. UE archive labels differ from descriptors: Complete RPG says 4.18; Damage/Resource/Stats says 5.0; FPS Multiplayer says 4.27. No UE5 conversion or automatic editor/plugin execution is implied. Unreal mirror provenance is recorded; no Fab ownership or licence was inferred.
