From request to result

  1. Choose your project. Use its actual path and source asset, package or document.
  2. Describe the result. Include the change, view or motion, target format and quality.
  3. Copy and send. Paste the edited request into WatooM Code. Copying here never starts a job.
  4. Review the evidence. Check real outputs and remaining blockers before accepting delivery.

Installed guidance is not a guarantee that every adapter, dependency or output is available. Sims modules check game-format support; prompt-builder skills only prepare prompts. Capture uses the native dispatcher and separate 4 GiB worker. Pose preparation supports qualified FK cases and needs asset-specific review.
