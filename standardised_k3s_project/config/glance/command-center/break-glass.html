Clear stale

Safe. Clears only what is provably orphaned: execution claims whose owner is interrupted and idle, finished or very old worker pods and units, and a GPU owner whose process has ended. Running work is never touched.

Force reset

Stops the app and every worker, clears all claims, queued inputs, running-job flags and any held deployment guard, recovers GPU ownership through the GPU controller, restarts the router and the app, then checks health. Running work is interrupted. Session history is kept and a database snapshot is taken first.
